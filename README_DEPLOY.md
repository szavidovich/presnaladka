# PRESNALADKA — site v1

Готова статична версія сайту для домену presnaladka.com.ua.

## Файли
- `index.html` — сайт
- `styles.css` — дизайн
- `script.js` — плавна навігація
- `CNAME` — домен для GitHub Pages

## Публікація через GitHub Pages
1. Завантажити ці файли у репозиторій.
2. У GitHub: Settings → Pages.
3. Source: Deploy from a branch.
4. Branch: master або main, папка `/ (root)`.
5. У Custom domain вказати `presnaladka.com.ua`.
6. Після цього налаштувати DNS в Imena.ua за значеннями, які покаже GitHub Pages.

Перед публікацією бажано додати реальні фото продукції та, за потреби, уточнити юридичне формулювання контактного блоку.
